# 約数の個数 (Number of Divisors)

配点 : 100 点

## 問題文
\(1\) 以上 \(10^{18}\) 以下の自然数 \(N\) が一つ与えられます。
\(1\) 以上 \(N\) 以下の自然数の中で、**約数の個数が最も多い自然数**を出力してください。
そのような数が複数ある場合は、それらをすべて小さい順に改行区切りで出力してください。

## 制約
* \(1 \le N \le 10^{18}\)
* \(N\) は整数である

## 入力
入力は以下の形式で標準入力から与えられます。

> \(N\)

## 出力
約数の個数が最も多い自然数を、小さい順に改行区切りですべて出力してください。

---

## 入力例 1
```text
1
```

## 出力例 1
```text
1
```
\(1\) 以上 \(1\) 以下の自然数は \(1\) のみであり、約数の個数は \(1\) 個（\(1\)）です。

## 入力例 2
```text
10
```

## 出力例 2
```text
6
8
10
```
$1$ 以上 $10$ 以下の自然数の約数の個数はそれぞれ以下のようになります。
* $1$: $1$ 個
* $2, 3, 5, 7$: $2$ 個
* $4, 9$: $3$ 個
* **$6$**: $4$ 個（$1, 2, 3, 6$）
* **$8$**: $4$ 個（$1, 2, 4, 8$）
* **$10$**: $4$ 個（$1, 2, 5, 10$）

したがって、約数の個数が最も多い（$4$ 個）自然数は $6, 8, 10$ の $3$ つとなります。
